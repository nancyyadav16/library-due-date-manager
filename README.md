# 📚 Library Due Date Manager

A simple C-based Library Management System designed to manage books and track their due dates.

## 🚀 Features

•⁠  ⁠Add New Books
•⁠  ⁠Display All Books
•⁠  ⁠Search Books
•⁠  ⁠Issue Books
•⁠  ⁠Return Books
•⁠  ⁠Track Book Due Dates
•⁠  ⁠Menu-Driven User Interface

## 🛠️ Technologies Used

•⁠  ⁠C Programming Language
•⁠  ⁠GCC Compiler
•⁠  ⁠Visual Studio Code
•⁠  ⁠Git & GitHub

## 📂 Project Structure

•⁠  ⁠main.c – Main program
•⁠  ⁠book.c – Book management
•⁠  ⁠date.c – Date handling
•⁠  ⁠library.h – Header file
•⁠  ⁠transactions.c – Book transactions

## ⚙️ How to Run

### Step 1: Clone Repository

git clone https://github.com/nancyyadav16/library-due-date-manager.git

### Step 2: Open Project Folder

cd library-due-date-manager

### Step 3: Compile

gcc main.c

### Step 4: Execute

./a.out

## 🎯 Project Objective

To develop a basic library management system using C programming concepts and provide an easy way to manage books and their due dates.
